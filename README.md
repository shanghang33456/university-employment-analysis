# 高校学生就业信息与去向分析平台

面向「初级前端工程师（可视化方向）」岗位能力训练的综合项目：基于 **Vue 3 + Vite + ECharts + Element Plus** 构建的毕业生就业数据可视化分析平台，覆盖 **就业去向、行业分布、薪资水平、地域流向、企业类型** 五大分析主题，并提供**数据来源与指标口径**追溯页面。

平台数据全部来自**公开官方统计发布**（广西教育厅、国家统计局、麦可思），不做任何数值编造；因为公开数据只到汇总层面，平台不提供个体级明细查询。

---

## 一、功能概览

| 模块 | 路径 | 核心内容 |
| --- | --- | --- |
| 数据总览 | `/dashboard` | 毕业生总数、去向落实率、单位就业占比、升学率、第一大行业 5 项 KPI；分学历落实率、去向结构环形图、行业 TOP8、单位性质 TOP6、国家战略地区流向、自动生成的数据洞察 |
| 就业去向 | `/destination` | 分学历 100% 去向堆叠、整体去向环形图、学历结构、单位就业内部构成、毕业去向明细表（分学历占比） |
| 行业分布 | `/industry` | 行业占比 TOP12、学历 × 行业热力图、行业年平均工资参照（非私营 vs 私营） |
| 薪资水平 | `/salary` | 城镇单位工资 KPI、分行业工资 TOP12（非私营 / 私营 / 规模以上切换）、分区域工资、分登记注册类型工资、行业工资增速、毕业生起薪参照 |
| 地域流向 | `/region` | 国家战略地区流向、分学历区域流向、留桂就业 14 市分布、分区域年平均工资参照 |
| 企业类型 | `/company` | 单位性质分布 TOP8、学历 × 单位性质热力图、分登记注册类型年平均工资 |
| 数据来源与口径 | `/sources` | 6 个公开数据源（机构 / 发布时间 / 原文链接 / 提供指标）、指标口径说明表、已知局限 |

**全局能力**

- **全局筛选联动**：受公开数据维度限制，全局筛选仅保留「学历」一项（学历是唯一贯穿去向 / 行业 / 单位性质 / 战略地区全部交叉表的维度），由 Pinia 统一管理，切换后全站图表自动重新请求并更新。
- **响应式适配**：≥1200px 三栏栅格、992–1200px 两栏、≤992px 侧边栏收起为抽屉 + 单列、≤640px 移动端单列布局。
- **交互反馈**：KPI 数字滚动动画、图表 loading 遮罩、页面切换过渡、筛选条件徽标计数、刷新按钮。
- **数据可追溯**：每个分析页顶部均标注数据来源编号与口径提示，可跳转 `/sources` 查看原文。

## 二、技术栈

| 分类 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | Vue 3.5 | 全部使用 `<script setup>` 组合式 API |
| 构建 | Vite 8 | 极速冷启动、原生 ESM、产物按依赖分包 |
| 可视化 | ECharts 6 | **按需引入**（仅注册用到的图表与组件），自注册统一主题 |
| 组件库 | Element Plus 2 | 通过 `unplugin-vue-components` **按需自动注册** |
| 状态管理 | Pinia 4 | `filter`（全局筛选）/ `app`（UI 状态）两个 store |
| 路由 | Vue Router 5 | 懒加载路由 + 路由元信息驱动菜单与面包屑 |
| 网络请求 | Axios | 统一实例、请求/响应拦截器、自定义 adapter 提供本地聚合接口 |

全部数值、出处链接与口径说明集中在 `src/data/employmentData.js`，页面不硬编码任何统计数字。使用前请留意：

- 数据范围为广西 2025 届毕业生，**不能代表全国或其他省份**；仅一个届别，无跨年趋势。
- 「国家战略地区」四类区域存在交叉，占比相加会超过 100%。
- 城镇单位年平均工资（S2）与毕业生起薪（S6）是两套口径，**不可直接比较**，页面中已分开展示。

## 五、快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（产物输出到 dist/）
npm run build

# 本地预览构建产物（默认 http://localhost:4173）
npm run preview
```

> 环境要求：Node.js ≥ 18。

### 关于接口层

数据以静态模块形式内置，由 `src/mock/handlers.js` 对外提供与后端一致的 RESTful 接口，
axios 通过自定义 adapter 直接调用这些处理器，因此**无需后端即可完整运行**。

```js
// src/api/request.js
const useMock = import.meta.env.VITE_USE_MOCK !== 'false'
```

若后续接入真实后端，将 `VITE_USE_MOCK` 设为 `false` 并配置 `VITE_API_BASE_URL` 即可切换，
业务代码与页面无需改动。

## 六、关键技术实现

### 1. 数据层与请求层解耦

`src/data/employmentData.js` 只负责「事实」：数值、出处 URL、口径说明；
`src/mock/handlers.js` 只负责「映射」：把汇总指标整理成图表可直接消费的结构。
新增数据源或调整图表结构时，二者互不影响。接口仍走 axios adapter，接入真实后端时移除 adapter 即可。

### 2. 全局筛选联动 + 竞态保护

`useAnalysisData` 把全局筛选序列化为依赖键，筛选变化时自动重新请求；使用自增序号丢弃过期响应，避免快速切换筛选时旧数据覆盖新数据。

### 3. 图表响应式

`useChart` 在容器上挂载 `ResizeObserver`，侧边栏折叠、窗口缩放、路由切换时图表自动 `resize()`；组件卸载时 `dispose()` 防止内存泄漏。

### 4. 性能优化

- Element Plus 组件与样式按需引入（非全量注册）。
- ECharts 仅注册实际使用的 4 种图表 + 6 个组件。
- 路由级代码分割，7 个业务页面均为懒加载。
- 依赖分包（`echarts` / `element-plus` / `vendor`），利用浏览器缓存。

构建产物（`npm run build`）：

| 产物 | 体积 | gzip |
| --- | --- | --- |
| echarts | 624.06 kB | 210.81 kB |
| element-plus (js) | 370.97 kB | 128.20 kB |
| element-plus (css) | 94.48 kB | 13.30 kB |
| vendor | 79.38 kB | 29.96 kB |
| index（布局 + 公共逻辑） | 29.58 kB | 11.50 kB |
| 各业务页面（懒加载） | 2.5 – 6.9 kB / 页 | 约 2 kB / 页 |

### 5. 响应式栅格

`src/styles/index.css` 定义 `.grid--kpi / .grid--2 / .grid--3 / .grid--2-1` 等类，配合 1200px、992px、640px 三档媒体查询；布局侧边栏在 ≤992px 时通过 `translate(-100%)` 收起为抽屉，配合遮罩与头部筛选按钮。

## 七、代码规范约定

- 统一 2 空格缩进、LF 换行、文件末尾换行（见 `.editorconfig`）。
- 组件文件使用 `PascalCase`，`composables` 以 `use` 前缀命名，工具函数使用 `camelCase`。
- Vue 组件一律使用 `<script setup>`，样式使用 `<style scoped>`。
- 接口统一在 `src/api/` 中声明，页面不直接引用 axios 实例。
- 统计数值统一收敛到 `src/data/employmentData.js`，页面与处理器不写死数字。
- 图表配置统一复用 `utils/chartOptions.js` 中的公共片段，保证视觉一致。

## 八、部署

```bash
npm run build      # 生成 dist/
```

将 `dist/` 目录部署到任意静态服务器（Nginx / 对象存储 / 静态托管平台）。由于使用 HTML5 History 路由，需配置**回退到 `index.html`**，例如 Nginx：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```
